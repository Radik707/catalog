## Ключевые риски v1.3

- **iOS квота ~50 МБ** — никогда не делать precache всех 900 фото. Только CacheFirst on-demand + maxEntries: 450.
- **7-дневный eviction iOS** — вызвать `navigator.storage.persist()` после первой синхронизации. Двойной слой SW Cache + IndexedDB страхует.
- **skipWaiting: true → ChunkLoadError** — оставить `skipWaiting: false`. Обновление SW только по явному действию.
- **Vercel кэширует sw.js с immutable** — добавить `Cache-Control: max-age=0, must-revalidate` в next.config.mjs.
- **SW в dev-режиме ломает разработку** — обязательно `disable: process.env.NODE_ENV === 'development'`.
- **SSR-данные офлайн пусты** — перевести CatalogView с `await getProducts()` на `useCatalogSync()` (этап 11).
- **Тестирование** — каждый этап, затрагивающий iOS-поведение, проверяется на РЕАЛЬНОМ iPhone (не в симуляторе).
