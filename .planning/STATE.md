## Ключевые риски v1.4

- **SSR-гидратация:** роль нельзя читать до монтирования — нейтральный дефолт, паттерн `useDeviceClass`.
- **force-dynamic:** не добавлять ISR/кэш на витрину и `/api/products` — сломает живое управление из панели.
- **Офлайн-совместимость:** история заказов (localStorage) и переключатель роли должны работать офлайн — без сетевых зависимостей при старте.
- **Честность истории заказов:** не называть «статус» — только «Отправленные заказы»; серверная история — задел под v2.0/Supabase.
- **Ключ матчинга товаров:** нормализованное имя — хрупко; для этапа 16 достаточно, для «Повторить заказ» (v1.5/этап 19) будет риск деградации по несовпадению имени.
