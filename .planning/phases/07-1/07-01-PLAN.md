# План 07-01: Подгруппы в админ-панели

> **Ретроспективный план (бэкфилл).** Этап отгружен в проде в рамках вехи v1.1,
> но формальный план GSD на момент работы не велся. Восстановлен 2026-06-10 при
> закрытии вехи для целостности дневника проекта. Итог — в `07-01-SUMMARY.md`.

## Цель

В админ-панели владелец при правке товара выбирает подгруппу новой двухуровневой
структуры; раздел определяется автоматически; правка сохраняется в память правок
и применяется upload.py — без поломки существующих правок v1.0.

## Задачи (выполнены)

- [x] Выпадающий список подгрупп в карточке товара (из `structure_map.json`)
- [x] Авто-предвыбор раздела по подгруппе (`SUBGROUP_TO_SECTION`)
- [x] Отправка правки `type="подгруппа"` в лист «Правки» через `sheet_helper.py`
- [x] Разворот правки в раздел/подгруппу в `upload.py` (`apply_subgroup_overrides`)
- [x] Тип «подгруппа» добавлен в белые списки `sheet_helper.py` и `upload.py`
