## Модель навигации (поведение аккордеона + показ товаров)

Владелец уточнил исходное видение: при первом входе видны ВСЕ товары, разложенные по разделам и подгруппам, листаются сверху вниз (Сладкое → Напитки → Бакалея…) — не свёрнутый аккордеон.

| Вариант | Описание | Выбран |
|--------|-------------|----------|
| Прыжок к разделу (якорь) | Все товары видны; полоса разделов прилипает; тап = плавная перемотка к разделу | ✓ |
| Фильтр по разделу | По умолчанию всё; тап оставляет только выбранный раздел | |
| Сворачивание разделов | Всё раскрыто, но заголовок можно свернуть тапом | |

**User's choice:** Делегировал выбор Claude как сеньору/дизайнеру → выбран вариант «меню-якорь» (anchor navigation).
**Notes:** Рекомендация обоснована паттерном приложений доставки еды (прилипающая полоса категорий + длинная прокрутка + scroll-spy). Закрывает сразу NAV-01/02/03. Товары — те же карточки/режимы.

## Новинки и «Все товары»

| Вариант | Описание | Выбран |
|--------|-------------|----------|
| «Новинки» первым разделом | Отдельный раздел первым в полосе и на витрине; ловит товары без раздела | ✓ |
| Только во вкладке «Новинка» | Без отдельного раздела на витрине | |

**User's choice:** «Новинки» первым разделом.
**Notes:** Продолжает решение «Новинки первыми» из Этапа 1; гарантирует, что товары с пустым «Раздел» не выпадут из навигации.

## Claude's Discretion

После закрытия четырёх областей владелец дал полную свободу по оставшимся мелочам («ответь сам по аналогии… правки потом на готовом проекте»):
- Счётчики товаров у заголовков подгрупп (ненавязчивые).
- Пустые подгруппы/разделы не отрисовываются (фильтр stock > 1).
- Отдельная кнопка «Все» не нужна (по умолчанию видно всё; возврат наверх — существующий ScrollToTop).
- Внешний вид заголовков раздел/подгруппа в духе текущего синего Tailwind-UI.
- В полосу выносятся только разделы (5–6), подгруппы — in-page заголовки.
- Техника scroll-spy и плавной перемотки — на усмотрение исполнителя.
