## Докачка новых фото при «Обновить»

| Option | Description | Selected |
|--------|-------------|----------|
| Новые — сразу, первая — лениво | Активный prefetch только новых (diff); первая загрузка не качает все 900 разом (защита iPhone) | ✓ |
| Только лениво | Фото кэшируются строго по мере просмотра; безопасно по трафику, но фото нового товара нет офлайн до открытия при сети | |
| Всё новое всегда | Активно качать всё новое включая первую загрузку; риск квоты iPhone и долгая первая загрузка | |

**User's choice:** Новые — сразу, первая загрузка — лениво (гибрид).
**Notes:** Новинок в день немного — активный prefetch diff копеечный. Потолок кэша 450 / 7 дней сохраняется.
