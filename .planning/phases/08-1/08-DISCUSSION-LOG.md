## Вид скрытой карточки в панели

| Вариант | Описание | Выбрано |
|---------|----------|---------|
| Тусклая карточка + смена иконки | Прозрачность ~45%, глазик 👁→🚫 (заложено в бэклоге) | ✓ |
| + текстовая метка «скрыт» | Дополнить чипом «скрыт» для однозначности в плотной сетке | ✓ (усиление) |

**Решение:** Тусклая карточка (~0.45) + чип «скрыт» в углу + смена иконки (открытый/перечёркнутый глаз). D-01…D-03.

## Кнопка-глазик: место и защита от случайного клика

| Вариант | Описание | Выбрано |
|---------|----------|---------|
| Угол фото, без подтверждения | Оверлей в правом верхнем углу фото, один клик, зона ≥44px | ✓ |
| С подтверждением | Модалка перед скрытием | |

**Решение:** Угол фото, ≥44px, БЕЗ подтверждения — действие обратимо одним кликом, модалка = лишнее трение. D-04…D-06.

## Момент применения скрытия на живом сайте

| Вариант | Описание | Выбрано |
|---------|----------|---------|
| После «Применить сейчас» | Единый механизм со всеми правками; в панели тускнеет сразу | ✓ |

**Решение:** После «Применить сейчас» — консистентность с существующим потоком, без спец-случая. D-07.
