## Единица счёта

| Option | Description | Selected |
|--------|-------------|----------|
| Всё в штуках, упаковка = шаг | Поле и корзина в штуках, «+1 блок» = +N шт | |
| В упаковках (блоки/коробки) | Поле показывает число упаковок, «+1» = +1 блок | |
| Гибрид: у каждого своя | Штучный — в штуках, блочный — в блоках, коробочный — в коробках | ✓ |

**User's choice:** Гибрид — у каждого товара своя естественная единица.
**Notes:** Уточняющий вопрос про смысл цифр в прайсе → владелец: цена указана по-разному — некоторые
товары за штуку, некоторые за пак/упаковку/блок. Это сделало гибрид технически чистым (цена и остаток
уже в единицах продажи).
