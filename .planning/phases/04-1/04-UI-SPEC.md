## Масштаб отступов

Многократность 4px. Соответствует Bootstrap 5, встроенному в Tabler.

| Токен | Значение | Применение |
|-------|----------|------------|
| xs | 4px | Зазор иконка–текст, inline-padding бейджей |
| sm | 8px | Отступы внутри карточки, padding ячейки таблицы |
| md | 16px | Отступы секций, padding формы |
| lg | 24px | Разделитель секций, padding страницы (горизонталь), padding Dropzone |
| xl | 32px | Отступы между крупными блоками |
| 2xl | 48px | Зарезервировано (пустые состояния) |
| 3xl | 64px | Не используется в этом этапе |

Исключения:
- Сенсорные кнопки (первичные действия): min-height 48px для надёжного нажатия пальцем (mobile-first).

**Примечание по Dropzone:** предыдущее значение `padding 28px` заменено на `24px` (токен `lg`) — приведено к стандартной шкале.

## Типографика

Три размера, два насыщения. Базовый подход идентичен `uploader/app.py`.

| Роль | Размер | Насыщение | Межстрочный интервал |
|------|--------|-----------|----------------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label / кнопки / заголовки карточек | 16px | 600 (semibold) | 1.4 |
| Page heading (h1 панели) | 20px | 600 (semibold) | 1.2 |

Мелкие вспомогательные подписи (timestamps, hints) — 14px regular (тот же body), визуально отделяются цветом (`text-muted`), не отдельным кеглем. Это устраняет неоднозначную ступень 13px, которая отличалась от body всего на 1px.

**Источник:** извлечено из CSS загрузчика (`uploader/app.py` строки 536–584) и приведено к Tabler.

## Цвет

Палитра сохраняет преемственность с загрузчиком (`uploader/app.py`). Tabler использует те же утилитарные цвета Bootstrap 5.

| Роль | HEX | Применение |
|------|-----|------------|
| Dominant (60%) | `#f3f4f6` | Фон страницы, фон вкладок |
| Secondary (30%) | `#ffffff` | Карточки товаров, панели форм, шапка |
| Accent (10%) | `#2563eb` | Только: активная вкладка-фильтр, кнопка «Сохранить правку», кнопка «Применить сейчас», выделение поиска |
| Destructive | `#dc2626` | Только: кнопка «Сбросить фото», цвет иконки удаления товара из правок |

Цвет акцента зарезервирован для конкретного списка — не для всех интерактивных элементов:
1. Кнопка «Сохранить правку» (форма правки товара)
2. Кнопка «Применить сейчас»
3. Активная вкладка-фильтр (Требуют внимания / Новинки / Без группы / Без фото / Все)
4. Рамка поля в фокусе (outline)

Семантические цвета состояний (наследуются из загрузчика):
- Успех: фон `#ecfdf5`, текст `#065f46`
- Ошибка: фон `#fef2f2`, текст `#991b1b`
- Информация / в процессе: фон `#eff6ff`, текст `#1e40af`
- Предупреждение (бейдж «требует внимания»): фон `#fef9c3`, текст `#92400e`

**Источник:** CSS-переменные из `uploader/app.py` строки 537–583.

## Экраны и компоненты

### Экран 1: Список товаров (главный)

**Маршрут:** `/<ADMIN_SECRET>/`

**Фокусная точка:** карточки с бейджем `!` (предупреждающий цвет `bg-warning-lt`, оранжевый) — первичный визуальный якорь, сигнализирующий, что товару нужно внимание. Вкладка «Требуют внимания» активна по умолчанию именно потому, что эти карточки — главное, зачем владелец открывает панель.

**Структура (mobile-first, max-width 640px, margin: 0 auto):**

```
┌────────────────────────────────┐
│  Заголовок «Вкусный Дом — Панель»
│  [Поиск по названию...]        │
│  ─ вкладки ────────────────── │
│  Требуют внимания · Новинки ·  │
│  Без группы · Без фото · Все   │
│  ──────────────────────────── │
│  ┌─────────────────────────┐   │
│  │ [!] Чипсы Estrella      │   │
│  │     Без группы · Без фото│  │
│  └─────────────────────────┘   │
│  ┌─────────────────────────┐   │
│  │ [N] Зефир «Ударница»    │   │
│  │     Новинка             │   │
│  └─────────────────────────┘   │
│  ...                           │
│  ─────────────────────────── │
│  [  Применить сейчас  ]        │
└────────────────────────────────┘
```

**Компоненты Tabler:**
- `card` — карточка товара (Tabler `.card`, `.card-body`)
- `badge` — бейдж статуса (`badge bg-warning-lt`, `badge bg-blue-lt`, `badge bg-red-lt`)
- `nav tabs` — вкладки-фильтры (Tabler `.nav-tabs` или кастомный `.filter-tabs`)
- `input` — поле поиска (`.form-control`)
- `btn btn-primary` — «Применить сейчас»

**Бейджи статусов товара:**
- `!` оранжевый (`bg-warning-lt`) — товар требует внимания (нет группы ИЛИ нет фото ИЛИ новинка)
- `Н` синий (`bg-blue-lt`) — только новинка (если группа и фото есть)
- Нет бейджа — товар в порядке

**Источник:** D-04 (04-CONTEXT.md).

### Экран 2: Правка товара

**Маршрут:** `/<ADMIN_SECRET>/item/<normalized_name>` или модальное окно поверх списка.

**Рекомендация исполнителю:** использовать отдельную страницу (не модал) — надёжнее с телефона, легче история браузера.

**Структура:**

```
┌────────────────────────────────┐
│  ← Назад к списку              │
│  ═══════════════════════════   │
│  Название (из прайса):         │
│  «Чипсы Estrella Начос 75г»    │
│                                │
│  Отображаемое название         │
│  [_______________________ ]    │
│  (пусто = название из прайса)  │
│                                │
│  Группа                        │
│  [▾ Выберите группу... ]       │
│                                │
│  Фото                          │
│  ┌──────────────────────────┐  │
│  │   [+] Загрузить фото     │  │
│  │   (или текущее фото)     │  │
│  └──────────────────────────┘  │
│                                │
│  [    Сохранить правку    ]    │
│  ─────────────────────────── │
│  [  Сбросить правки товара ]   │
└────────────────────────────────┘
```

**Компоненты Tabler:**
- `form-label` + `form-control` — поле названия
- `form-select` — выпадающий список групп (11 групп из category_map.json)
- Dropzone (Tabler `dropzone` или нативный `<input type="file" accept="image/*" capture="environment">`) — загрузка фото, padding 24px
- `btn btn-primary` — «Сохранить правку»
- `btn btn-danger btn-ghost` — «Сбросить правки товара» (деструктивное, только при наличии правок)

**Источники:** D-05, D-06 (04-CONTEXT.md).

## Интерактивные состояния

### Кнопка «Применить сейчас»

| Состояние | Внешний вид | Поведение |
|-----------|-------------|-----------|
| Обычное | `btn btn-primary`, активна | Запускает пересборку каталога |
| Идёт обработка | `disabled`, текст «Обновление уже идёт...» | Недоступна (переиспользует PROCESS_LOCK) |
| Нет последней партии | `disabled`, текст «Нет данных прайса» | Недоступна |
| После нажатия | Banner `.status.info` под кнопкой | Сообщение об успехе, кнопка разблокируется через 30 с |

### Форма правки товара

| Поле | Состояние | Поведение |
|------|-----------|-----------|
| Название | пустое поле = используется из прайса | hint под полем всегда виден |
| Группа | при наличии правки — предвыбран текущий override | если правки нет — выбрано значение из прайса |
| Фото | при наличии правки — превью текущего фото | кнопка «Загрузить новое» поверх превью |
| Кнопка «Сохранить правку» | `disabled` пока нет изменений | активируется при любом изменении поля |

### Поиск

- Живой фильтр: список товаров фильтруется по мере ввода (debounce 300ms).
- Поиск по оригинальному названию из прайса (normalize_name-совместимый).
- При пустом результате — пустое состояние «Товары не найдены по этому фильтру».

## Реестр безопасности

| Реестр | Используемые блоки | Проверка безопасности |
