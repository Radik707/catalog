<objective>
Первый сквозной «ломтик» админ-панели: владелец открывает защищённую страницу, видит товары, требующие внимания, **меняет группу любого товара** и нажимает «Применить сейчас». Это доказывает, что весь стек работает: авторизация секретом → чтение «Товары» → форма → запись в «Правки» → пересборка каталога.

Purpose: дать владельцу первую реальную возможность управлять каталогом без программиста (ADM-01, ADM-02, ADM-05). Группа уже поддержана памятью правок этапа 3 — панель только записывает строку.
Output: `scripts/sheet_helper.py` (утилита Sheets), `uploader/admin.py` (страница + маршруты), правка `uploader/app.py` (монтирование).
</objective>

## Phase Goal

**As a** владелец каталога, **I want to** открыть защищённую панель, найти товар без группы и назначить ему группу из списка, **so that** при следующем обновлении каталог покажет товар в правильном разделе — без участия программиста.
