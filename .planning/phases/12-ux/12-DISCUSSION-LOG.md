## Индикатор сети

| Вариант | Описание | Выбран |
|---------|----------|--------|
| Показывать всегда | Полоска статуса видна постоянно, даже онлайн со свежими данными | |
| Показывать по необходимости | Скрыта при онлайн+свежие; нейтральная при офлайн; жёлтая при >24ч | ✓ |

**Решение (Claude):** D-01/D-02/D-03 — полоска скрыта при онлайн+свежих данных, нейтральная (серая) при офлайн, жёлтая при данных старше суток. Место — тонкая строка под синей шапкой. Офлайн оформляется спокойно, не красным (офлайн — норма для агента в полях).

## Формат времени

| Вариант | Описание | Выбран |
|---------|----------|--------|
| Абсолютное «за 08:30» | Время последней синхронизации; для прошлых дней — с датой | ✓ |
| Относительное «2 часа назад» | Относительный возраст данных | |

**Решение (Claude):** D-04 — абсолютное с адаптацией по дате: сегодня «за 08:30», вчера «за вчера, 08:30», раньше «за 10 июня, 08:30». Точнее отвечает на вопрос «насколько свеж каталог».

## Кнопка заказа

| Вариант | Описание | Выбран |
|---------|----------|--------|
| Выключенная + подпись | Серая `disabled` кнопка с постоянным пояснением под ней | ✓ |
| Реакция при нажатии | Активная кнопка, показывает сообщение при попытке отправить офлайн | |

**Решение (Claude):** D-05 — выключенная кнопка + постоянная подпись «Нет сети — заказ отправится, когда появится интернет. Корзина сохранена.» Сразу честно показывает «сейчас нельзя», без ощущения «сломалось». Касается обеих кнопок отправки.

## Корзина офлайн

| Вариант | Описание | Выбран |
|---------|----------|--------|
| Без отличий | Набор/удаление одинаковы онлайн и офлайн (уже так) | ✓ |
| С офлайн-подсказками | Пометки/бейджи «офлайн» на корзине | |

**Решение (Claude):** D-06 — никаких офлайн-отличий в корзине. Уже работает через localStorage. Единственное офлайн-отличие во всём потоке — заблокированная кнопка отправки (D-05). CART-01 — преимущественно проверка (включая ручную iPhone-приёмку).
