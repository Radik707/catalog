## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| navigator API → UI | Состояние сети из браузера управляет disabled-состоянием кнопок (доверенный источник) |
| localStorage → UI | Корзина читается/пишется в localStorage (данные самого приложения, не внешний ввод) |
| UI → Telegram deep link | Открытие `https://t.me/...` с текстом заказа (исходящая ссылка; текст формируется из локальной корзины) |

Новых серверных эндпоинтов и секретов нет. Текст заказа уже проходит `encodeURIComponent` (существующий код, не меняется).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-04 | Spoofing | navigator.onLine как единственный признак сети | accept | navigator.onLine может ложно показывать «онлайн» при подключении без интернета; для UX-блокировки кнопки это приемлемо — заказ всё равно открывается в Telegram, корзина сохраняется в localStorage (потери данных нет) |
| T-12-05 | Tampering | Текст заказа в deep link | accept | Текст формируется из локальной корзины пользователя и кодируется encodeURIComponent (существующий код); внешнего ввода нет |
| T-12-06 | Tampering | npm-зависимости | accept | План не добавляет npm-пакетов; package legitimacy gate не применим |
</threat_model>
