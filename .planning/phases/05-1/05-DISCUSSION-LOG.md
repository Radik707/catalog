## Старая колонка «Группа» (техническое — решение сеньора)

| Option | Description | Selected |
|--------|-------------|----------|
| Оставить «Группа» | Витрина пока работает по ней — не ломаем до Этапа 6 | ✓ |
| Заменить на «Раздел»/«Подгруппа» | Сразу убрать старое поле | |

## Порядок и кластеры (техническое — решение сеньора)

| Option | Description | Selected |
|--------|-------------|----------|
| Позиция в JSON | Порядок = позиция в массиве, без числовых полей | ✓ |
| Числовые поля сортировки | order: 10, 20… | |

**Решение:** Один файл `structure_map.json`, порядок = позиция в списке; кластеры (Подарочные, Энергетики-последними) — через порядок категорий. → D-01, D-02, D-05
**Notes:** Владельцу-непрограммисту проще править руками; числовые поля рассинхронизируются.
