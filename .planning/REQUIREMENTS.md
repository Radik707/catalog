# Требования: Каталог «Вкусный Дом» — веха v1.5 «Опыт клиента (телефон)»

**Определено:** 2026-06-28
**Core Value:** Владелец магазина быстро открывает каталог, в один тап повторяет прошлый заказ, видит свою историю заказов и привычную «Главную» с короткими путями — минимум листания, максимум доверия.

> Требования предыдущих вех (v1.0–v1.4) — в `.planning/MILESTONES.md` и `.planning/PROJECT.md` (раздел Validated).
> Основа вехи: исследование `.planning/ozon-research-and-split.md` + мастер-план `.planning/audience-split-roadmap.md` (§5).
> Опирается на фундамент v1.4: роль `client`/`sales` (этап 15) и локальная история заказов `useOrderHistory` (этап 16).

## Требования v1.5 «Опыт клиента (телефон)»

Объём текущей вехи. Каждое требование привязывается к этапу дорожной карты. Все требования — только для роли «Клиент»; роль «Торговый» (планшет) этой вехой не задеваем.

### Нижняя навигация-табы (TABS) — этап 18, закрывает C2, C5

- [ ] **TABS-01**: В роли «Клиент» снизу видна панель с 3 вкладками (Каталог · Избранное · Корзина); активная вкладка подсвечена; зона нажатия дотягивается большим пальцем
- [ ] **TABS-02**: На вкладках «Избранное» и «Корзина» — бейджи-счётчики; стиль согласован с существующим счётчиком корзины
- [ ] **TABS-03**: В роли «Торговый» нижней панели НЕТ — навигация остаётся в шапке как сейчас (нижние табы — антипаттерн для планшета)
- [ ] **TABS-04**: Нижняя панель не перекрывает контент и плавающие кнопки (ContactFab, ScrollToTop); работает офлайн и в standalone-PWA (safe-area снизу учтён, как в этапе 14)

### Повторить заказ + «Мои заказы» (REORD) — этап 19, закрывает C1, C4

- [ ] **REORD-01**: Экран «Мои заказы» показывает локальную историю отправленных заказов (дата-время, сумма, число позиций, канал); пустое состояние понятно оформлено
- [ ] **REORD-02**: Кнопка «Повторить» подставляет позиции выбранного прошлого заказа в корзину — повтор в один тап (доступно из карточки заказа; на «Главной» — опционально, этап 20)
- [ ] **REORD-03**: При повторе цена и наличие берутся **актуальные** (с учётом формы цен +5% Ефимова), а не замороженные из истории; недоступные/изменившиеся/исчезнувшие товары честно помечаются («нет в наличии» / «цена изменилась» / «товар больше недоступен»)
- [ ] **REORD-04**: Вход на экран «Мои заказы» — из нижних табов или меню (роль «Клиент»); в роли «Торговый» экран доступен, но не навязывается

### Чистый вход клиента (HOME) — этап 20, закрывает C3

> ⚠️ **Переосмыслено 2026-06-29** (см. `phases/20-client-clean-entry/20-CONTEXT.md`): отдельная
> «Главная» с блоками-витринами снята — каталог = главная. Вместо неё — разгрузка шапки и быстрый повтор.

- [x] **HOME-01**: В роли «Клиент» верхняя панель не дублирует нижние табы (убраны верхние ♥ и 🛒, остаётся ⚙), **разделы** вынесены на первый план; в роли «Торговый» шапка не меняется
- [x] **HOME-02**: Над каталогом — одна компактная строка «↻ Повторить последний заказ» (если есть история): тап → позиции в корзину с актуальной ценой/наличием и честной сводкой (механика этапа 19)
- [x] **HOME-03**: Всё новое работает офлайн (localStorage/IndexedDB) и не ломает PWA/standalone; `force-dynamic` витрины и `/api/products` не затронуты

### История поиска (SRCH) — этап 20, закрывает O5

- [x] **SRCH-01**: Поиск показывает недавние запросы и/или подсказки по началу ввода; история запросов хранится локально (localStorage), офлайн-безопасна

## Будущие требования (необязательные улучшения)

Полезны, но не входят в MVP вехи; добавим, если останется бюджет или появится спрос.

- **VIEWED-01** *(C6, низкий приоритет)*: Блок «Недавно смотрели» на «Главной» — включается, если останется бюджет этапа 20; иначе переносится в будущую веху
- **REORD-05**: Повтор отдельных позиций (не всего заказа целиком) — точечный повтор по галочкам
- **SRCH-02**: Подсказки по популярным товарам/категориям, а не только по истории запросов

## Вне области (Out of Scope)

Явно исключено — чтобы не было расползания объёма вехи v1.5.

| Фича | Причина |
|------|---------|
| Quick-order набор, кратность упаковки, наличие числом, «Показ клиенту», корзина по поставщику | Это веха v1.6 (опыт торгового) — отдельная ветка опыта |
| Любые изменения опыта роли «Торговый» (планшет) | v1.5 — только телефонный опыт клиента; торгового не трогаем |
| Серверная история заказов (Supabase) | Решено: история локально; серверная — вместе с аккаунтами v2.0 |
| Стабильный SKU/артикул, сканер штрихкода, шаблоны заказа по клиенту | Задел под v2.0/1С — в `.planning/BACKLOG.md`; повтор заказа в v1.5 живёт на хрупком ключе (имя) с мягкой деградацией |
| Рейтинги/отзывы/«N купили»/сравнение товаров | B2C-доверие к незнакомцу; в B2B доверие исходит от торгпреда — антипаттерн (отчёт §6) |
| Изменение серверной части/пайплайна прайсов | v1.5 — чистый фронт; сервер daniella не трогаем |
