**Определено:** 2026-06-30
**Core Value:** Торговый представитель быстро набирает крупные заказы (ввод количества прямо в строке, шаг кратно упаковке), ясно видит наличие числом, одной кнопкой показывает товар лицом клиенту и комплектует заказ по поставщику — минимум тапов, максимум скорости в полях.

## Требования v1.6 «Опыт торгового (планшет)»

Объём текущей вехи. Каждое требование привязывается к этапу дорожной карты. Все требования — только для роли «Торговый»; клиентский опыт v1.4/v1.5 (телефон) этой вехой не задеваем.

### Quick-order набор + кратность упаковки (QORD) — этап 21, закрывает T1, T2

- [x] **QORD-01**: В роли «Торговый» доступен режим «Быстрый набор» — плотные строки товаров с прямым вводом числа с клавиатуры и кнопками шага «+/−»; добавление в корзину без перехода/флипа/галереи
- [x] **QORD-02**: Шаг «+/−» и быстрые кнопки учитывают фасовку товара (за шт / блок / коробку / ящик) — кратность упаковки; меньше тапов и ошибок при опте (расширение существующих ~40 правил фасовки)
- [x] **QORD-03**: Введённое количество мгновенно отражается в корзине и в итоге; ограничение по остатку соблюдается (кап по stock)
- [x] **QORD-04**: Режим набора привязан к роли «Торговый» — в роли «Клиент» он скрыт и не является дефолтом; клиентский опыт не затронут
- [x] **QORD-05**: Производительность на ~800 строк приемлема при прямом вводе (виртуализация списка — только если реально тормозит)

### Наличие/остатки (STOCK) — этап 22, закрывает T3

- [ ] **STOCK-01**: В роли «Торговый» остаток показан числом (не только «есть/нет»); фильтр «только в наличии» работает поверх разделов и поиска
- [ ] **STOCK-02**: Текущее правило скрытия товара с остатком ≤1 согласовано с новым отображением остатка числом — нет конфликта/двусмысленности

### Режим «Показ клиенту» (SHOW) — этап 22, закрывает T5

- [ ] **SHOW-01**: Кнопка «Показ клиенту» переводит в чистый режим показа: крупное фото (Lightbox), без цен и служебных кнопок; выход одним жестом. Доступен в обеих ролях, но в роли «Торговый» — заметным действием
- [ ] **SHOW-02**: В режиме показа цены скрыты **принудительно**, независимо от настройки «С ценами» — чтобы случайно не показать клиенту закупочную цену

### Корзина с разбивкой по поставщику (SUPCART) — этап 23, закрывает T4

- [ ] **SUPCART-01**: В роли «Торговый» корзина группирует позиции по поставщику с подытогом по каждому поставщику
- [ ] **SUPCART-02**: В роли «Клиент» корзина остаётся простой (плоский список + общий итог) — без разбивки по поставщику
- [ ] **SUPCART-03**: К заказу можно добавить комментарий; он попадает в текст заказа Telegram/MAX
- [ ] **SUPCART-04**: Текст заказа для торгового структурирован по поставщику (подытоги + общий итог); для клиента формат остаётся как сейчас

## Будущие требования (необязательные улучшения)

Полезны, но не входят в MVP вехи; добавим, если останется бюджет или появится спрос.

- **SUPCART-05** *(T4-опц., низкий приоритет)*: Если у поставщика задана минимальная сумма заказа — корзина подсвечивает недобор; данные минималок — отдельный источник, заводится только если решим (нет данных в прайсах сейчас)
