# Requirements: Каталог «Вкусный Дом» — Двухуровневая навигация (v1.1)

**Defined:** 2026-06-09
**Core Value:** Клиент быстро находит нужное — сверху мало крупных разделов, внутри понятные подгруппы; каталог остаётся актуальным и не «ломается».

## v1.1 Requirements

Требования текущей вехи. Каждое привязывается к этапу дорожной карты.

### Структура данных (STRUCT)

- [ ] **STRUCT-01**: существует карта «категория → подгруппа» (расширение `category_map.json`) — каждая категория каталога отнесена к подгруппе
- [ ] **STRUCT-02**: существует карта «подгруппа → раздел» (5 разделов) с явным порядком разделов на витрине
- [ ] **STRUCT-03**: задан порядок подгрупп внутри каждого раздела (например, «Энергетики» последними в «Напитки»)
- [ ] **STRUCT-04**: `upload.py` записывает для каждого товара его раздел и подгруппу (поля, которые читает витрина)
- [ ] **STRUCT-05**: внутри подгруппы поддержана кластеризация по смыслу — «Подарочные» идут кучей внутри «Конфеты»

### Перекладка групп по смыслу (REGRP)

- [ ] **REGRP-01**: группа «Стоевъ и Сэнсой» (по поставщику) расформирована — товары распределены по смыслу (соусы → Соусы, консервация → Консервация, лапша → Лапша, сок → Напитки, уксус/приправа → Соусы)
- [ ] **REGRP-02**: «Конфеты и печенье» разделена на «Конфеты» и «Печенье и вафли» (Сладонеж = вафли)
- [ ] **REGRP-03**: варпаки Мистраль попадают в подгруппу «Крупы и бакалея»

### Навигация витрины (NAV)

- [ ] **NAV-01**: на витрине вместо плоских 14 групп показываются 5 разделов верхнего уровня
- [ ] **NAV-02**: нажатие на раздел раскрывает его подгруппы аккордеоном — на месте, без перехода на отдельный экран
- [ ] **NAV-03**: внутри подгруппы показываются товары (карточки/список — как сейчас)
- [ ] **NAV-04**: разделы и подгруппы отображаются в заданном порядке из карты структуры
- [ ] **NAV-05**: поиск и существующие фильтры продолжают работать поверх новой двухуровневой структуры (не ломаются)

### Админ-панель (ADM, продолжение)

- [ ] **ADM-06**: в админ-панели при правке товара владелец выбирает **подгруппу** из новой структуры (а не плоскую группу)
- [ ] **ADM-07**: выбранная подгруппа сохраняется в память правок и применяется при следующем обновлении; раздел определяется автоматически по карте структуры

## Завершено (веха v1.0 «автоматизация и админ-управление»)

Закрыто 2026-06-07 (этапы 1–4). Оставлено для прослеживаемости.

- ✓ FMT-01…FMT-05 — поддержка нового формата 1С (авто-определение, боевой прогон)
- ✓ GRP-01…GRP-03 — группировка нового формата + «Новинки»
- ✓ UPL-01…UPL-04 — асинхронный загрузчик, история, результат в Telegram
- ✓ MEM-01…MEM-03 — память правок (вкладка «Правки», авто-применение)
- ✓ ADM-01…ADM-05 — админ-панель: доступ, правка группы/названия, фото, выделение требующих внимания
