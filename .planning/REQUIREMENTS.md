# Требования: Каталог «Вкусный Дом» — веха v1.2

**Определено:** 2026-06-10
**Core Value:** Каталог всегда актуален и не «ломается»; клиент быстро находит нужное. Владелец сам управляет витриной без правки кода.

## Требования v1.2

Объём текущей вехи «Скрытие товаров и десктоп-вид». Каждое требование привязывается к этапу дорожной карты.

### Скрытие товаров (HIDE)

- [ ] **HIDE-01**: Владелец может скрыть товар с витрины кнопкой-«глазиком» в карточке админ-панели
- [ ] **HIDE-02**: Владелец может вернуть скрытый товар обратно повторным нажатием «глазика»
- [ ] **HIDE-03**: Скрытая карточка в админ-панели визуально отличается (тусклая) и иконка отражает текущее состояние
- [x] **HIDE-04**: Скрытие сохраняется в памяти правок (тип «скрыт») и переживает перепрогон прайсов
- [x] **HIDE-05**: Скрытые товары не попадают на витрину — отсутствуют в ответе `/api/products` (фильтрация на сервере)

### Десктопный вид витрины (DESK)

- [ ] **DESK-01**: На большом экране витрина использует ширину экрана (больше колонок / просторнее), оставаясь читаемой
- [ ] **DESK-02**: Карточка товара адаптирована под десктоп — фото, название, цена и кнопка корзины соразмерны и не «разъезжаются»
- [ ] **DESK-03**: Двухуровневая навигация (разделы → подгруппы) удобна и кликабельна на десктопе
- [ ] **DESK-04**: Мобильный вид не ухудшается — это адаптивная вёрстка под один сайт, а не отдельная версия

### Десктопный вид админ-панели (ADESK)

Админ-панель — отдельное Flask-приложение (`uploader/admin.py`), не витрина. Владелец иногда работает с компьютера.

- [ ] **ADESK-01**: На большом экране админ-панель использует ширину экрана (больше колонок / просторнее) с разумным пределом ширины, оставаясь читаемой
- [ ] **ADESK-02**: Карточки и элементы управления (поля, кнопки, списки, фото-редактор) адаптированы под десктоп — соразмерны и не «разъезжаются»
- [ ] **ADESK-03**: Управление удобно для мыши — зоны клика адекватны курсору, нет мелких нечитаемых и нет впустую «пальцевых» элементов
- [ ] **ADESK-04**: Мобильный вид админ-панели не ухудшается — адаптив одного интерфейса, не отдельная версия

## Будущие требования (v1.3+)

Признаны, но отложены — не входят в текущую дорожную карту.

### Офлайн-режим / PWA

- **PWA-01**: Каталог устанавливается как приложение (PWA) и открывается без браузерной обвязки
- **PWA-02**: Фото и данные кэшируются при утренней загрузке и доступны без интернета
- **PWA-03**: Без сети можно листать каталог, переключать разделы, открывать фото, набирать корзину

## Вне области (Out of Scope)

Явно исключено — чтобы не было расползания объёма.

| Фича | Причина |
|------|---------|
| Офлайн-режим / PWA | Большая отдельная веха v1.3 — требует стратегии кэша ~900 фото |
| Telegram-бот «Каталог-консультант» | Отдельная крупная веха, не связана со скрытием/десктопом |
| Автоновинки (авто-снятие бейджа через 2 недели) | Отдельная будущая веха, зависит от памяти правок |
| Фикс CR-01 (новый формат 1С → раздел/подгруппа) | Латентный техдолг, ждёт уточнения формата у 1С-программиста |
| Удаление товара из данных | Скрытие — это флаг, товар остаётся в листе, чтобы его можно было вернуть |
| Десктоп как отдельная версия сайта | Делаем адаптив одного сайта, не второй интерфейс |
