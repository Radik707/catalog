# Требования: Каталог «Вкусный Дом» — веха v1.3

**Определено:** 2026-06-12
**Core Value:** Торговый агент работает с каталогом весь день в полях без интернета — утром разово обновился, дальше всё под рукой без сети.

> Требования предыдущих вех (v1.0–v1.2) — в `.planning/MILESTONES.md` и `.planning/PROJECT.md` (раздел Validated).

## Требования v1.3 «Оффлайн-режим (PWA)»

Объём текущей вехи. Каждое требование привязывается к этапу дорожной карты. Опирается на `.planning/research/SUMMARY.md`.

### Офлайн-каталог (OFF)

- [ ] **OFF-01**: Открыв приложение без сети, агент видит весь каталог (товары, цены, остатки, бейджи) — данные берутся из локального хранилища на телефоне
- [ ] **OFF-02**: Без сети работает навигация — переключение разделов и подгрупп, поиск и фильтры по уже загруженным данным
- [ ] **OFF-03**: Данные каталога хранятся в надёжном локальном хранилище (IndexedDB) и переживают закрытие приложения

### Офлайн-фото (IMG)

- [ ] **IMG-01**: Фото просмотренных товаров доступны без сети (кэшируются по мере просмотра, не все ~900 разом)
- [ ] **IMG-02**: Полноэкранный просмотр и зум фото работают офлайн для уже закэшированных фото
- [ ] **IMG-03**: Кэш фото имеет разумный предел и не переполняет хранилище телефона — особенно на iPhone (лимит ~50 МБ)

### Установка как приложение (PWA)

- [ ] **PWA-01**: Каталог устанавливается на домашний экран и запускается как приложение, без браузерной строки
- [ ] **PWA-02**: На Android агент получает подсказку об установке; на iPhone — понятная инструкция «Поделиться → На экран Домой»

### Обновление и свежесть (SYNC)

- [ ] **SYNC-01**: Кнопкой «Обновить» агент по требованию подтягивает свежий каталог и новые фото (при наличии сети)
- [ ] **SYNC-02**: Обновление фото умное — докачиваются только новые/изменившиеся фото, не весь набор заново
- [ ] **SYNC-03**: Видно состояние сети (онлайн/офлайн) и метку «данные за ЧЧ:ММ» — агент понимает, насколько свежий каталог

### Корзина офлайн (CART)

- [ ] **CART-01**: Набор корзины работает без сети — товары добавляются и удаляются офлайн
- [ ] **CART-02**: Отправка заказа требует сети — офлайн кнопка «Отправить» заблокирована с понятным пояснением (заказ не теряется молча)

## Будущие требования (v1.3.x — необязательные улучшения)

Признаны полезными, но не входят в MVP вехи; добавим после базового оффлайна, если понадобятся.

- **SYNC-04**: Прогресс синхронизации («Загрузка фото: 23/47 новых»)
- **PWA-03**: Баннер «Доступно обновление приложения» (мягкое обновление service worker по согласию)
- **IMG-04**: Кнопка «Очистить кэш фото»
- **IMG-05**: Показ занятого объёма хранилища (`navigator.storage.estimate()`)

## Вне области (Out of Scope)

Явно исключено — чтобы не было расползания объёма.

| Фича | Причина |
|------|---------|
| Фоновая авто-синхронизация (Background Sync) | Ненадёжна на iOS — только ручная кнопка «Обновить»; отложено в v2+ |
| Push-уведомления об обновлении каталога | Отдельная тема, не нужна для оффлайн-работы; v2+ |
| Персональный кэш/данные по агентам | Это многопользовательность — отдельная веха v2.0 (см. `PRODUCT-VISION.md`) |
| Кнопка «скачать все ~900 фото разом» | Риск переполнить лимит iOS; решение зависит от замера размера фото; не в MVP |
| Переход на нативное приложение / магазины приложений | Остаёмся на PWA; обёртку в Google Play (TWA) рассмотрим при продаже продукта |
| Изменение серверной части, Google Sheets API, пайплайна прайсов | Оффлайн делается на клиенте; серверная часть не трогается |
