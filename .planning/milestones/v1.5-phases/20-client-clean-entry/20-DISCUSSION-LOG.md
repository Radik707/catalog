## Поворотный момент обсуждения

Исходно этап планировался как «стартовая Главная» с блоками-виджетами (Повторить · Избранное · Хиты + крупный поиск) — паттерн Ozon/WB. При первом раунде вопросов владелец **поставил под сомнение саму идею** отдельной Главной: «смысл каталога — это сам каталог», предупредил про «свалку» из ненужных обвесов, указал на **дублирование** навигации шапка ↔ нижние табы и попросил вынести **разделы** на первый план в шапке. Координатор согласился (B2B ≠ B2C), сверился с кодом (подтвердил дубли ♥/🛒 у client) и **переформатировал этап** в «Чистый вход клиента». Решение зафиксировано вторым раундом вопросов.

## Когда / где показывать «Главную»

| Вариант | Описание | Выбран |
|--------|-------------|----------|
| Верх экрана «Каталог» | Главная как стартовое состояние каталога; таб «Каталог» возвращает на него | (отменено пересмотром) |
| Отдельная 4-я вкладка «Дом» | Явный возврат, но 4 таба тесно на телефоне | |
| Только при первом входе | Главная один раз, дальше каталог | |

**Выбор владельца (свободный текст):** «Для чего вообще нужна главная, если смысл каталога — это сам каталог — достаточно одной страницы каталог. Верхнюю панель нужно передумать: сейчас есть повторение Каталог в верхней панели и внизу. Сверху важнее иметь список разделов.»
**Итог:** отдельная Главная отвергнута → этап переформатирован (см. ниже).

## Состав и порядок блоков + «Недавно смотрели»

| Вариант | Описание | Выбран |
|--------|-------------|----------|
| Поиск→Повторить→Хиты→Избранное | Порядок блоков витрины | (отменено пересмотром) |
| Поиск→Повторить→Избранное→Хиты | Избранное выше Хитов | |
| Включить «Недавно смотрели» | +блок VIEWED-01 с отслеживанием просмотров | |

**Выбор владельца (свободный текст):** «Недавно смотрели — вообще не нужно (клиент смотрит с витрины, не открывая товар). Повторить — есть уже в корзине, нужно ли дублировать на главной. Будь внимателен с ненужными обвесами и нагромождениями.»
**Итог:** блоки-витрины отвергнуты; VIEWED-01 выкинут; повтор сведён к одной компактной строке (см. ниже).

| Вариант | Описание | Выбран |
