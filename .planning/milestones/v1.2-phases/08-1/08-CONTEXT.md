# Phase 8: Скрытие товаров «глазиком» - Context

**Gathered:** 2026-06-10
**Status:** Ready for planning

<domain>
## Phase Boundary

Владелец одним нажатием кнопки-«глазика» в карточке админ-панели скрывает товар с витрины и так же возвращает его обратно. Скрытие хранится в «памяти правок» (новый тип `скрыт`) и переживает перепрогон прайсов (`upload.py`). Скрытые товары фильтруются на сервере витрины и не попадают в ответ `/api/products`. Товар при этом ОСТАЁТСЯ в листе «Товары» Google Sheet (не удаляется) — чтобы его можно было вернуть в любой момент.

**Вне этапа:** десктопный вид витрины (этап 9), удаление товаров из данных, любые изменения, не связанные со скрытием.
</domain>

<decisions>
## Implementation Decisions

Все решения ниже приняты в режиме «сеньор решает сам» (владелец делегировал технические и UX/продуктовые решения — см. память проекта `senior-decisions-autonomously`). Владелец подтвердил мандат в обсуждении 2026-06-10.

### Вид скрытой карточки в админ-панели
- **D-01:** Скрытая карточка визуально тускнеет (полупрозрачность ~0.45, класс вида `.pcard.hidden`) — чтобы состояние читалось мгновенно. Карточка остаётся полностью интерактивной (чтобы товар можно было вернуть).
- **D-02:** Дополнительно к прозрачности — маленькая текстовая метка/чип «скрыт» в углу карточки, чтобы состояние было однозначным даже в плотной сетке (density-s) и при беглом просмотре. Не полагаться только на прозрачность.
- **D-03:** Иконка глазика отражает текущее состояние по универсальной метафоре: открытый глаз = товар ВИДЕН (клик → скрыть); перечёркнутый/закрытый глаз = товар СКРЫТ (клик → вернуть). Понятно без подписи.

### Кнопка-глазик: расположение и защита от случайного клика
- **D-04:** Кнопка-глазик размещается оверлеем (`position: absolute`) в правом верхнем углу области фото карточки. Не смешивать с зоной названия/селекторов, чтобы не путать с правками названия/группы.
- **D-05:** Зона нажатия ≥44px — соответствует уже принятому в панели touch-стандарту (`min-height: 44px` у существующих кнопок карточки).
- **D-06:** БЕЗ диалога-подтверждения. Один клик переключает состояние, возврат — тоже один клик. Действие неразрушающее (товар остаётся в таблице) и мгновенно обратимое; подтверждение на каждое скрытие = лишнее трение при управлении сотнями карточек. Поведение оптимистичное (UI обновляется сразу, как у остальных правок).

### Момент применения скрытия на живом сайте
- **D-07:** Скрытие применяется на витрине клиента ПОСЛЕ кнопки «Применить сейчас» (тот же перепрогон `upload.py`, что и все остальные правки). Единый механизм — предсказуемо, без спец-случая. В админ-панели карточка тускнеет мгновенно (оптимистично); на сайте клиента товар исчезает после применения. Это сознательное решение ради консистентности с существующим потоком правок — НЕ делать отдельный путь «мгновенного» скрытия в обход «Применить сейчас».

### Поиск и возврат скрытых товаров
- **D-08:** В админ-панель добавить фильтр видимости — переключатель «Показать скрытые» (или 3-состояние: Все / Только видимые / Только скрытые). По умолчанию — показывать все товары, скрытые отображаются тусклыми в общем списке. Фильтр обслуживает требование HIDE-02 (вернуть товар): при ~900 товарах без него скрытый товар сложно найти, чтобы вернуть.
- **D-09:** Фильтр клиентский (по уже загруженным в панель товарам) + работает совместно с существующим поиском по панели. Не делать отдельный серверный эндпоинт.

### Claude's Discretion
Помощник-планировщик/исполнитель имеет свободу в:
- Технической реализации, зафиксированной как архитектура в `.planning/BACKLOG.md` (новый тип правки `скрыт` в трёх белых списках; колонка «Скрыт» (L) в КОНЕЦ строки Sheet по паттерну expand-contract; расширение диапазона чтения витрины `A2:K` → `A2:L`; фильтрация скрытых на сервере в `lib/sheets.ts`; поле `hidden?: boolean` в `Product`).
- Точных CSS-значениях (оттенок прозрачности, размеры), точном тексте чипа «скрыт», конкретных глифах иконки глазика (👁 / 🚫 / 🙈 / SVG) — в рамках решений D-01…D-08.
- Способе реализации фильтра видимости в UI (кнопка-тумблер vs сегментированный переключатель) — D-08/D-09 задают суть, не вёрстку.

<code_context>
## Existing Code Insights

### Reusable Assets
- **Механизм «памяти правок»** (тип правки `подгруппа`, этап 7): полностью переиспользуется как образец для типа `скрыт`. Тот же путь: запись через `/save` в админ-панели → хранение → разворот в `upload.py` → колонка в Sheet.
- **Оптимистичный UI карточки** (admin.py): существующий паттерн мгновенного обновления карточки после правки — переиспользуется для переключения глазика.
- **Touch-стандарт `min-height: 44px`** (admin.py CSS): применяется к кнопке-глазику.
- **Селекторы `.pcard-*` и режимы плотности `density-l/m/s`** (admin.py CSS): метка «скрыт» и кнопка-глазик должны корректно выглядеть во всех трёх режимах плотности и в обоих видах (grid/list).

### Established Patterns
- **Expand-contract для колонок Sheet:** новые колонки (например «Подгруппа» J, «Раздел» K) добавляются В КОНЕЦ строки, не сдвигая существующие. Колонка «Скрыт» = L (12-я). Этот же паттерн обязателен здесь.
- **Тип правки в ТРЁХ белых списках:** `upload.py` ALLOWED_TYPES, `sheet_helper.py` ALLOWED_TYPES, `admin.py` SAVE_ALLOWED_TYPES. Забыть один → правка молча пропадёт (известные грабли).
- **Пустое значение = снятие правки:** как у `badge`/`photo`, для типа `скрыт` значение `1` = скрыт, пустая строка = показан. `/save` должен разрешать пустое значение для `скрыт`.
- **Фильтрация на сервере витрины:** скрытые товары не отдавать в браузер вообще (фильтр в `getProducts`, `lib/sheets.ts`), а не прятать на клиенте — безопаснее (HIDE-05).

### Integration Points
- **Витрина читает Google Sheet напрямую** (`lib/sheets.ts`, `force-dynamic`): диапазон `A2:K` → `A2:L`; читать колонку L → `Product.hidden`; фильтровать скрытые в `getProducts`.
- **Витрина обновляется только после перепрогона** (`upload.py` через «Применить сейчас»): отсюда решение D-07 — скрытие на сайте применяется после «Применить сейчас», как все правки.
- **Деплой раздельный:** витрина (`lib/*`, `app/*`) — Vercel сам по git push; сервер (`scripts/*.py`, `uploader/admin.py`) — через сисадмина (pull + restart службы `catalog-uploader` + перепрогон). См. память `server-via-sysadmin`.

</code_context>

## Specific Ideas

- Иконка-глазик как основной управляющий элемент скрытия (метафора «показать/скрыть»), в углу фото.
- Скрытая карточка «тускнеет» — визуальная метафора «выключенного» товара, привычная по другим интерфейсам.
- Фильтр «Только скрытые» — чтобы владелец мог быстро провести ревизию скрытого и вернуть нужное.
