## Найденная и закрытая недоделка (gap)

При проверке владелец обнаружил: после «Применить сейчас» (без деплоя) скрытие **не отражалось на витрине до 5 минут** — товар оставался виден. Причина — два слоя ISR-кэша по 300 с:
- `lib/sheets.ts`: `fetch(url, { next: { revalidate: 300 } })`
- `app/catalog/[secret]/page.tsx`: `export const revalidate = 300`

Деплой сбрасывал кэш, поэтому скрытие появлялось только при следующем пуше — отсюда симптом «пропадает только когда меняю фото и деплою».

**Починка (коммит `6437674`):**
- `lib/sheets.ts` → `fetch(url, { cache: "no-store" })` — витрина читает лист «Товары» свежим при каждом заходе.
- `app/catalog/[secret]/page.tsx` → `export const dynamic = "force-dynamic"` (вместо `revalidate = 300`).
- `app/api/products/route.ts` → убран `revalidate = 300` (остался `force-dynamic`), чтобы не конфликтовал с `no-store`.

Обоснование: трафик B2B небольшой, постоянное чтение Google Sheets при заходе допустимо; зато «Применить сейчас» отражается на витрине сразу. Владелец подтвердил: после починки скрытие работает без деплоя.
