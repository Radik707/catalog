## Внешний вид панели (поднято владельцем)

Владелец попросил подобрать готовую панель на GitHub, чтобы выбрать глазами. Senior пояснил разницу между
админ-«движками» (требуют БД+API — не подходят к Google-таблице) и визуальными HTML-шаблонами (подходят).

| Вариант | Описание | Выбран |
|---------|----------|--------|
| Tabler | Чистый HTML/Bootstrap 5, MIT, mobile-first, Dropzone/галерея/карточки/формы | ✓ |
| AdminLTE | Классика, проверенная, чуть строже на вид | |
| Админ-движки (React Admin/AdminJS/Django Admin) | Требуют БД+API — дороже адаптировать | |
| Отдельная панель на Vercel/Next.js | Дублирует доступы — отклонено | |

**Выбор владельца:** Tabler. **Примечание:** проверены демо-страницы Tabler под задачи (фото/карточки/формы) —
ложатся. Хранение фото — существующий Cloudinary.

## Многопользовательский режим (поднято владельцем)

Владелец спросил про возможность создавать аккаунты другим торговым представителям, чтобы они работали «от себя».

| Вариант | Описание | Выбран |
|---------|----------|--------|
| Отложить на будущую веху | Сейчас панель для одного владельца; мультиарендность — отдельный большой проект | ✓ |
| Сначала обсудить идею | Понять масштаб/сроки/заработок до решения | |

**Выбор владельца:** Отложить на будущую веху.
**Примечание:** Senior пояснил, что это мультиарендность (своя таблица/фото/бот/ссылка у каждого, логины, изоляция) —
по объёму больше всех 4 этапов. Записано в `<deferred>` как кандидат в новую веху.

## Главный экран панели (ADM-05)

**Выбор:** делегировано senior (владелец не возражал против рекомендации).
**Решение:** по умолчанию «Товары, требующие внимания» (новинки / без группы / без фото) + вкладки-фильтры
(Требуют внимания · Новинки · Без группы · Без фото · Все) + поиск по названию; карточка → экран правки.

## Привязка фото (ADM-04)

**Выбор:** загрузка с телефона (из ответов владельца: «загружать фотографии, чтобы сохранялись», «заменять фото»).
**Решение:** загрузка с телефона → Cloudinary (`presenter/`) → привязка типа `photo` в память. Замена = повторная
загрузка. Вариант «выбрать из уже загруженных» — отложен.

## Редактирование полей и цена (ADM-02, ADM-03)

| Вариант (правка цены) | Описание | Выбран |
|-----------------------|----------|--------|
| Разовая — потом 1С главнее | Применяется сейчас, следующий прайс перекрывает | |
| Постоянная — всегда моя цена | Риск заморозить товар на старой цене | |
| Цену вообще не правим в панели | Цена чинится в 1С; правим группу/название/фото | ✓ |

**Выбор владельца:** Цену в панели не правим (чинится в 1С).
**Примечание:** редактируем группа/название/фото; название — новый тип правки `name` (расширение памяти этапа 3).
