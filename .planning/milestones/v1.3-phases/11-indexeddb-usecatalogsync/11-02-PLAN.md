Логика по D-01 (stale-while-revalidate): сначала мгновенно читаем `Product[]` из IndexedDB, параллельно делаем `fetch("/api/products")` и бесшовно подменяем массив.     Создай клиентский хук `lib/useCatalogSync.ts` с директивой `"use client"` и комментариями на русском. Импортируй `useState`/`useEffect`/`useCallback` из react, `Product` из `@/lib/types`, функции `getProducts`/`saveProducts`/`getMeta`/`saveMeta` из `@/lib/catalogDb`.

    Определи и экспортируй тип результата. Хук `useCatalogSync()` возвращает объект:
    - `products: Product[]` — текущий массив (из IDB, затем подменяется свежим с сервера);
    - `isOnline: boolean` — состояние сети;
    - `syncedAt: number | null` — время последней успешной синхронизации (из meta-ключа `syncTimestamp`);
    - `status: "loading" | "ready" | "empty-offline"` — для UI плана 03. `loading` = IDB пуст и идёт первый fetch (D-02 скелетон); `ready` = есть товары (из IDB или с сервера); `empty-offline` = IDB пуст И (нет сети ИЛИ fetch не удался) (D-03 заглушка).

    Состояние через useState: products (нач. `[]`), isOnline (нач. `true` при SSR, на клиенте — `navigator.onLine`), syncedAt, status (нач. `"loading"`). Флаг «первая синхронизация выполнена» держи в useRef, чтобы persist() вызвать единожды.

    Основная функция синхронизации `sync()` (через useCallback):
    1. Прочитать `cached = await getProducts()`. Если `cached.length > 0` — `setProducts(cached)` и `status = "ready"` (мгновенный рендер из кэша, D-01).
    2. Прочитать `syncTimestamp` из meta → setSyncedAt.
    3. Если `navigator.onLine === false`: если кэш пуст — `status = "empty-offline"`; завершить (без fetch).
    4. Если онлайн — `fetch("/api/products")`. Если ответ не `ok` — выбросить/перейти в ветку catch (D-04). Иначе `fresh: Product[] = await res.json()`:
       - `setProducts(fresh)` — бесшовная подмена (хук возвращает новый массив, компонент перерисовывает список, НЕ размонтируясь — позиция прокрутки/фильтры/раздел сохраняются, т.к. они в состоянии CatalogView);
       - `await saveProducts(fresh)`, `now = Date.now()`, `await saveMeta("syncTimestamp", now)`, `setSyncedAt(now)`, `status = "ready"`;
       - один раз (по useRef-флагу) вызвать `if (navigator.storage?.persist) await navigator.storage.persist()`.
    5. В `catch` (сеть упала / сервер ошибся, D-04): если кэш был пуст — `status = "empty-offline"`, иначе оставить `"ready"` на данных IDB. Тех. ошибку НЕ пробрасывать в UI (можно console.warn для отладки).

    В `useEffect` (один раз при монтировании): вызвать `sync()`; подписаться на `window` события `online` (→ setIsOnline(true) и повторный `sync()` — авто-подтягивание по D-03) и `offline` (→ setIsOnline(false)); вернуть cleanup-функцию, снимающую обе подписки (отписки — Claude's Discretion).

    Не обращайся к `navigator`/`window` на верхнем уровне модуля — только внутри useEffect/коллбэков (безопасно для серверной сборки Next.js).
