## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → проект | Установка пакетов @serwist/next, serwist, idb — цепочка поставки |
| Service worker → клиент | SW перехватывает HTTP-запросы; работает в привилегированном scope `/` |
| Vercel CDN → браузер агента | Заголовки кэширования влияют на доставку sw.js |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-SC | Tampering | npm install @serwist/next, serwist, idb | mitigate | Блокирующий human-verify чекпойнт (Task 1): пакеты [ASSUMED] (нет audit-table в research), проверка на npmjs.com до установки. Чекпойнт не авто-одобряется. |
| T-10-01 | Tampering | Service worker scope `/` (Service-Worker-Allowed: /) | accept | Scope `/` нужен для будущего кэша корневых путей; SW отдаётся только с секретного origin каталога, новых публичных эндпоинтов нет. Низкий риск. |
| T-10-02 | Denial of Service | CacheFirst Cloudinary без лимита → QuotaExceededError | mitigate | ExpirationPlugin maxEntries: 450 заложен в app/sw.ts как каркас (D-16); офлайн-эффект и iOS-квота проверяются на этапе 13. |
| T-10-03 | Tampering | Vercel залипает на старом sw.js (immutable) | mitigate | Заголовок Cache-Control: max-age=0, must-revalidate для /sw.js (D-14) — SW всегда ревалидируется. |
</threat_model>
