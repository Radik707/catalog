## Название приложения

**Решение (принято по делегированию):** Полное — «Каталог Вкусный Дом»; короткое (под иконкой) — «Вкусный Дом».
**Notes:** Под иконкой влезает ~12 символов; «Каталог» отброшен ради читаемости.

## Иконка приложения

**Решение:** Логотипа нет → генерируем монограмму «ВД» белым по синему `#2563eb`, скруглённый квадрат; PNG 192/512 + maskable + apple-touch-icon.
**Notes:** Временная, легко заменяемая на реальный логотип позднее.

## Цвет и заставка

**Решение:** `theme_color` = `#2563eb` (синий шапки каталога); `background_color` = `#ffffff` (белый).
**Notes:** Фирменный синий взят из реального кода — `layout.tsx:28` `bg-blue-600`.

## Поведение при запуске

**Решение:** `display: standalone`; `start_url` = секретный путь каталога с `CATALOG_SECRET`; тап по иконке → сразу главная каталога.
**Notes:** Единственное осмысленное поведение; секрет берётся из переменной окружения.
