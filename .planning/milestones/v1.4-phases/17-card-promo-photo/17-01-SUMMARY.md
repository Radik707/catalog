## Что было сделано

В ветке `role === "client"` компонента `CardCornerButton.tsx` заменена одиночная кнопка-сердечко на вертикальный стек двух кнопок в общем позиционирующем контейнере:

```
div.absolute.top-1.right-1.z-10.flex.flex-col.gap-1
  ├─ <button> сердечко (toggleFavorite) — всегда
  └─ <button> стрелки (onPhotoOpen)     — только при canOpenPhoto && size!=="sm"
```

Ключевые детали реализации:
- **Контейнер-стек** `absolute top-1 right-1 z-10 flex flex-col gap-1` — кнопки больше не имеют индивидуального `absolute`-позиционирования, идут вертикально с отступом `gap-1`
- **Стрелки** — дословная копия SVG и `onClick` из ветки `sales` (строки 45–66): `e.stopPropagation()` + `onPhotoOpen?.()`, `aria-label="Открыть фото на весь экран"`
- **Режим списка** (`size="sm"`): стрелки скрыты — переменная `showExpandBtn = canOpenPhoto && size !== "sm"`. Обоснование: миниатюра 14×14 не вмещает две кнопки аккуратно. В сетке и презентации стрелки обязательны.
- **SSR-заглушка** `if (!ready) return <div .../>` — не тронута, пустое место прежнего размера до загрузки роли
- **Ветка `sales`** (строки 44–66) — текстуально не изменена (D-06 соблюдён)
