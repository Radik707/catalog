# План: доработки каталога-сайта + авто-новинка (UX-апгрейд)

> Утверждён 2026-06-25. Исполняется по этапам с атомарными коммитами (для отката).
> Роль: эксперт-исполнитель; к владельцу — только за ручными браузерными проверками и крупными развилками.

## Утверждённые решения
1. **Форма цен**: по умолчанию 2-я (текущие цены). При 1-й форме +5% (×1.05) на товары Ефимовой — везде: каталог + корзина + текст заказа. Переключатель в шестерёнке.
2. **Планшет vs телефон/ПК**: `matchMedia("(pointer: coarse) and (min-width: 768px)")` → планшет (стрелки «развернуть фото»); иначе → сердечко (избранное). Приблизительно ≈7.5″.
3. **Корзину правим** (мини-фото + редактируемое количество). Параллельную MAX-сессию вливаем первой.
4. **Бейдж**: текст зелёного чипа «новинка» → «NEW».

## Опорные факты из кода
- Карточка [components/ProductCard.tsx]: тап по фото → Lightbox; тап по телу → переворот; на телефоне имя скрыто (на обороте). Зелёный бейдж «новинка» уже есть.
- Шестерёнка [components/CatalogSettings.tsx] + [components/SettingsPanel.tsx]: вид/фото/цены/плотность в localStorage. Сюда — форма цен и перенос кнопки «Обновить».
- `product.supplier` = имя файла («Ефимова.xlsx»). Ефимова = `/ефим/i`. Данные менять не нужно.
- Корзина [lib/useCart.ts] хранит базовую цену → +5% применять в момент показа/заказа.
- Авто-новинка частично есть [scripts/upload.py:1208-1225]: новый товар → «Новинки» + «новинка», но навсегда. Нужно истечение через 14 дней.
- Админка [uploader/admin.py] — на daniella; серверный деплой через субагента sysadmin.

## Этапы

### Этап 0 — Фундамент
- `lib/useDeviceClass.ts` — хук isTabletLike (SSR-safe).
- `lib/pricing.ts` — isEfimova(supplier) + effectivePrice(product, form).
- `lib/useFavorites.ts` + `components/FavoritesProvider.tsx` (по образцу useCart, localStorage `catalog-favorites`).
- Монтирование FavoritesProvider в [app/layout.tsx] рядом с CartProvider.

### Этап 1 — Угловая кнопка карточки + Избранное
- Тап по фото → переворот; Lightbox только по кнопке-стрелкам.
- Угловая кнопка: планшет → ⤢ (Lightbox); телефон/ПК → ♥ (избранное).
- Шапка: справа ♥ · ⚙ · 🛒; кнопка ↻ «Обновить» → внутрь панели шестерёнки.
- Режим `fav` в NavProvider; фильтр в CatalogView; сердечко в шапке со счётчиком.

### Этап 2 — Переключатель формы цен (шестерёнка)
- `priceForm: "1"|"2"` (по умолч. "2") в CatalogSettings + ползунок в панель.
- effectivePrice везде: лицо/оборот (сетка+список), Lightbox, строка корзины+итог, текст заказа Telegram+MAX.

### Этап 3 — Карточка-презентация на телефоне
- По умолчанию 2×3 на телефоне (через useDeviceClass, если нет сохранённого выбора).
- Полное имя + описание на лице; имя без обрезки, шрифт авто-уменьшается. Итеративно, со скриншотами.

### Этап 4 — Корзина + редактируемое количество
- Мини-фото слева в строке корзины (~56px).
- Редактируемое количество (inputmode=numeric, только цифры, авто-выделение, ограничение остатком) — корзина + AddToCartButton. Переиспользуемый QuantityInput.

### Этап 5 — Верхняя панель: «подглядывание» + UX-проход
- Градиент у правого края + наполовину видимая иконка. Конкретные правки со скриншотом.

### Этап 6 — Авто-новинка с истечением 14 дней (сервер)
- `scripts/novelty_dates.json` — дата первого появления.
- «NEW» + «Новинки» только ≤14 дней; затем авто-снятие. Ручная правка владельца побеждает.
- Админка: «новинка — осталось N дней».
- Деплой на daniella через sysadmin. Решить: novelty_dates.json в git или серверный runtime.

## Правила исполнения
- На каждом этапе: `Remove-Item -Recurse -Force .next ; npm run build` → скриншот/ручная проверка → локальный коммит.
- Push/деплой (Vercel, daniella) — внешнее действие, подтверждать перед выполнением.
- Параллельная MAX-сессия трогает корзину + ContactFab — правки корзины после её вливания.
