## 🛒 Витрина и навигация (доводки)

- **[БАГ] Навигация из корзины** — когда в корзине есть товары, нельзя выйти, нажав «Каталог» или раздел: работает только кнопка «выйти из корзины» внутри. Сделать шапку (Каталог/разделы) кликабельной из любого раздела, включая корзину. _S · 📋 готов — быстрый фикс_
- **Разложить раздел «Прочее»** — 6 категорий (Кофе, Чай Ахмад, Милкис, Попкорн, Снеки, Шоколад Милка большая) + 4 товара «без категории» по местам, чтобы «Прочее» исчез. _S · 🔄 в работе (на паузе)_
- **Скрытие карточек в админ-панели (глазик)** — в углу карточки в админ-панели кнопка-глазик: нажал → глазик перечёркнут, товар НЕ показывается на сайте, а карточка в панели тускнеет (видно, что скрыта). Нужен новый тип правки «скрыт» в памяти правок; upload.py исключает скрытые из витрины; панель показывает их приглушёнными. _M · 📋 готов к планированию_
- **Адаптация карточек под десктоп** — сейчас всё заточено под телефон; на большом экране можно красивее. _M · 💡_

## 🚀 Крупные фичи (кандидаты в новые вехи)

- **Telegram-бот «Каталог-консультант»** — бот консультирует клиентов по товарам (ИИ) и принимает заказы на тех же данных. Спроектирован в CLAUDE.md (grammY + Gemini, корзина в Vercel KV). _L · 📋 готов к планированию_
- **Автоновинки** — новые товары из прайсов автоматически получают бейдж «новинка» на 2 недели, потом он снимается сам. _M · 💡_
- **Интеграция с AkiTorg** — заявка с каталога уходит в приложение торгового агента (через 1С; публичного API нет — нужно исследование). _L · 💡 нужно исследование_
- **Офлайн-режим (мини-приложение / PWA)** — каталог работает как приложение: фото и данные кэшируются при утренней загрузке и доступны без интернета. Без сети можно листать, переключать вкладки, открывать фото на увеличение, набирать корзину. Технически — PWA + service worker + стратегия кэша (≈900 фото — нужен умный кэш, не всё сразу). _L · 💡 нужна отдельная проработка_
